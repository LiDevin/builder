# Only claim technical skills with current, concrete, verifiable evidence

This site lists Python, JavaScript, and BigQuery/SQL as technical skills because each has a
specific, real story behind it (the Rogers ad-creative JavaScript/DOM manipulation, the Rogers
Python scraper, the dentsu BigQuery dashboard). It deliberately omits Node.js despite Devin having
built a site with it five years ago — that experience is stale and unpracticed, and an
unverifiable "proficient" claim is a real interview risk for a role that may include technical
screening. Any future skill added to the homepage or an Experience page must have an equally
concrete, current story behind it, or it should be left off.
